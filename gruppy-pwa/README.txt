ГРУППЫ — PWA для iPad, версия 1

СОДЕРЖИМОЕ
index.html, app.js, styles.css, icon.svg, manifest.webmanifest, sw.js.

УСТАНОВКА
1. Разместите все файлы на HTTPS-сайте (например, на GitHub Pages, Netlify или собственном хостинге). Нельзя полноценно подключить Google OAuth при открытии файла напрямую с диска (file://).
2. Откройте адрес сайта в Safari на iPad → Поделиться → На экран «Домой».
3. В Google Cloud Console создайте проект, включите Google Drive API, настройте OAuth consent screen и Web OAuth Client ID. Укажите адрес сайта в Authorized JavaScript origins. Если режим Testing, добавьте свой Google-аккаунт в тестовые пользователи. Область доступа: https://www.googleapis.com/auth/drive. Google может запросить проверку приложения при публикации для широкой аудитории.
4. В Google Drive создайте пустую папку и скопируйте ссылку на неё.
5. В приложении «Настройки» введите OAuth Client ID и ссылку/ID папки. Нажмите «Подключить Google Drive» и дайте разрешение.
6. При открытии приложение будет автоматически пытаться восстановить авторизацию и прочитать содержимое папки. Google может потребовать повторный вход: без серверного OAuth-бэкенда гарантировать полностью невидимый вход после окончания токена нельзя. Данные последней загрузки доступны локально.

ФОРМАТ ДАННЫХ
_groups.json — список групп.
YYMMDD-Фамилия-Имя.json — отдельный файл участника. Если совпадают дата, имя и фамилия, к имени файла добавляется короткий UUID во избежание перезаписи.
При добавлении участника автоматически устанавливается ISO-дата addedAt.
Кнопка «Убрать» скрывает участника только на этом устройстве, не удаляя и не изменяя его JSON в Google Drive. Восстановление — в Настройках.

ВАЖНО
Это прототип v1. Нельзя гарантировать синхронизацию локально созданных записей при сбоях сети: они сохраняются в локальном кэше, но требуют последующей отправки. Для надёжной фоновой синхронизации, автоматического входа без диалога и работы на нескольких iPad нужен серверный бэкенд с OAuth refresh tokens, очередью изменений и разрешением конфликтов. Не публикуйте секреты OAuth в клиентском коде.


ВЕРСИЯ 2
Поиск в верхней панели. Список участников без отдельных карточек; каждая строка отделена линией.
Стрелка раскрывает адрес, телефон и другие сведения. Меню «…» позволяет редактировать или
удалять участника из локального списка без изменения JSON-файла в Google Drive.
На iPad кнопки видны постоянно, так как нет наведения мышью.

ОБНОВЛЕНИЕ НА GITHUB
Откройте репозиторий Gruppen-pwa, папку gruppy-pwa, и замените файлы index.html,
app.js, styles.css, sw.js из этой версии (остальные можно оставить прежними).
Данные Google Drive и локальные настройки сохраняются, так как ключи хранения не менялись.
